# 全漢方製薬会社 検索システム

日本の主要漢方製薬メーカー（ツムラ、クラシエ、小太郎漢方製薬、イスクラ産業、ウチダ和漢薬など）の全漢方処方・一般用漢方製剤・単味生薬製剤を一括横断検索・比較できるWebアプリケーションです。

## 主な機能
- **処方名・生薬名・効能効果 横断検索**（漢字・ひらがな・カタカナ・処方番号対応）
- **生薬除外検索（「□を除く」）**（特定生薬を含まない処方の絞り込み）
- **製薬会社・剤形・医療用/一般用 区分フィルター**
- **他社製品 配合比較表**（処方ごとの生薬分量・1日服用量・用法・添加物・使用上の注意の一括比較）
- **しおり型ブックマーク機能**
- **レスポンシブ対応・高速ローカル検索**
